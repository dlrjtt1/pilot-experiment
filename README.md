# Online Listening Experiment — Direct vs. PA-Reinforced Sound

A browser-based listening experiment investigating how the time
difference (ITDG) and level ratio between stage direct sound and
PA-reinforced sound affect auditory localization judgments in a
simulated concert hall.

## Overview

- 9 stimulus conditions: ITDG (0 / 20 / 40 ms) × level ratio (−6 / 0 / +6 dB)
- Stimuli rendered with binaural room impulse responses (BRIR)
- Reference stimulus: direct path only
- 3 evaluation items per condition
  - Q1 Clarity of sound image direction
  - Q2 Timbral naturalness
  - Q3 Sound image stability
- 3 repeated sets, randomized presentation order within each set

## Participant-side controls

- Left/right channel confirmation before the session
- Playback device (headphone / earphone) reporting
- Repeated presentation to check response consistency

## Structure

- `index.html` — experiment interface
- `audio/` — stimulus files
- `peaks/` — waveform data
